# 献立決定＆レシピ検索システム

専門学校1年生の時に、**初めてチーム開発で制作した**思い出のJava製コマンドラインアプリケーションです。
日々の夕食選びをサポートするために、1週間の献立をランダム（重複なし）で自動決定する機能や、選んだレシピをテキストファイルとして出力する機能を備えています。
ファイルを発掘したのでGitHubにアップしておきました。

## 👥 開発のエピソード
プログラミングを学び始めて1年目の頃、チームメンバーと一緒に初めて形にしたアプリケーションです。
条件分岐（`switch-case`）、配列、ループ処理、そしてファイル入出力（`FileWriter`/`PrintWriter`）など、当時学んだJavaの基礎を総動員して、実用性にこだわって作り上げました。

## 主な機能
1. **夕食の候補一覧表示:** 登録されている夕食（うどん、カレー、ハンバーグ等）の一覧と、それぞれの詳細なレシピを確認できます。
2. **献立決定機能:** 1週間（日〜土）の夕食メニューを、重複がないように自動でランダム抽選して提案します。
3. **検索機能:** キーワード入力によって、登録されているメニューを検索できます。
4. **レシピの外部出力:** レシピを表示した際、その内容を `Recipe.txt` というテキストファイルとしてローカル環境に保存できます。

## 動作環境
- Java SE (JDK) がインストールされている環境

## 実行方法 ▶️

1. リポジトリから `sougou.java` をダウンロードします。
2. ターミナル（またはコマンドプロンプト）を開き、ファイルがあるディレクトリに移動します。
3. 以下のコマンドを実行してアプリを起動します。

```bash
java sougou.java
```
